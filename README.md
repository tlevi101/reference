# Reference works
This repository collects my most important projects, from university and my other personal projects. 
## Thesis
My most interesting project is my thesis. Which is a multiplayer game with continous comminication between players (WebSockets).
Players must destroy the enemy with a math function graphs.

Key features:
- User management: Admin, players and guests.
- Live communication between players.
- Game queue.
- Map editor, custom games.
- Player friend relation.
- Math function parsing.
Project available at this repository: [Function-wars](https://github.com/tlevi101/Function-wars)

I have also deployed so it can be accessed without cloning the project and installing every dependency. [Site](https://function-wars.firebaseapp.com/) (The first login will be slow because the backend server is in idle state if there is no activity. It might take minutes until it wakes up.)
